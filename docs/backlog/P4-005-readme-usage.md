# P4-005 README Usage

## Story

As a contributor, I want clear README usage instructions so that I can run and extend the tool without reading the source first.

## Scope

- installation or run instructions
- environment configuration
- CLI examples
- test instructions

## Proposed Changes

- expand `README.md`
- add examples for text and JSON output
- document required environment variables and common workflows

## Acceptance Criteria

- README explains how to run the scanner locally
- README explains how to run tests
- README explains required environment variables for LLM-assisted mode

## Dependencies

- depends on the CLI stories being mostly settled
